# 社区规则策略的来源与接入范围

## 已找到的实现

[中文使用指南](https://hisoutensoku-cn-wiki.vercel.app/FAQ/Others/th123AI.html)提供神 AI 压缩包下载。
[th123_ai 源码](https://github.com/click3/th123_ai)实现了读取游戏内存、执行 Lua 脚本和发送键盘输入。
[日文维护页面](https://wikiwiki.jp/th123ai/)保留了使用资料，也记录了 AIManager 的故障。
本项目读取脚本研究策略，不运行 AIManager。

研究时使用的版本：

- 程序源码提交：`4cd9d204f353dd10d3c483dcea1b429d341171de`。
- [脚本压缩包](https://gitee.com/sanhuizhuan/SokuMods/releases/download/v1/th123ai.zip) SHA256：`b79cedc384f7e1a8060b7958aa1fdc24a334ceee364a4ba5ecbc2612a7fb3c18`。
- 包内文件：`th123ai/script/01_marisa_main.ai`、`00_reimu_main.ai`、`function_command.txt`、`def_clc.lua`。

程序源码与角色脚本分别由不同作者维护。仓库不重新分发下载包和角色脚本。下面的 Python 策略是依据规则思路独立实现的有限子集，不直接加载原 Lua 文件。

## 规则与实现的对应关系

| 原脚本中的规则 | 本项目实现 | 差异 |
| --- | --- | --- |
| 魔理沙脚本中普通攻击在命中停顿剩余 1 至 3 帧时继续 A 连段 | `community_combo` 根据自身动作和对手受击状态接 A，空中对手接前 B | 只支持灵梦、魔理沙；不移植符卡连段、随机压制和全部取消路线。 |
| 魔理沙脚本 1448 行起按对手角色、动作选择蹲防 | `community_guard` 对灵梦和魔理沙保留低段动作分类 | 未使用原版碰撞框、攻击标志、反应延迟及天气分支，不能保证正确防住所有招式。 |
| 脚本依据倒地动作 97、98 选择移动起身 | 两种策略按边界位置选择方向并保持有限帧数 | 去除原版随机选择。 |
| `function_command.txt` 的 `lvr236` 逐帧输入下、下前、前加攻击 | 两种策略在地面中距离执行相对朝向的 236B | 固定默认技能，不适配技能卡换招。 |
| 原版多帧 `yield`、`wait` 与按键释放 | 每个策略实例保存独立的动作队列 | 以模拟帧为时钟，不使用系统键盘或窗口焦点。 |

数字方向采用格斗游戏小键盘记法：2 是下，3 是下前，6 是前。236B 表示依次输入这三个方向，在最后一个方向按 B。

## 完整神 AI 尚需哪些工作

现有桥接提供位置、速度、动作、停顿、手牌及对象信息，但没有输出碰撞框矩形、全部连段计数和角色专用状态。
原脚本的 `get_obj_attackarea`、`get_hitarea`、`get_special_data` 等函数依赖这些数据。不能用零填充来冒充兼容。

完整移植的次序是：扩展状态协议并核对字段；实现 Lua API；按模拟帧恢复协程；每个玩家隔离 Lua 状态和随机数；最后比较相同输入下的脚本动作记录。
原程序依赖前台窗口和系统按键，不能直接用于当前无界面多实例采样。

新策略只是结构更复杂的对照组。是否更强，必须由固定规则下的双方对战结果判断。
