# 社区规则子集的真实对战结果

## 实验范围

2026-09-29，在 32 个物理 CPU 核的 Linux 服务器上，通过 Wine 10.0 运行原始 1.10a 游戏。使用 `tools/evaluate.py`、`config/evaluation.yaml` 和三个固定游戏种子：1397705557、1397705558、1397705559。

五个策略构成 15 个无序组合，包括五个自我对战组合。每个种子中每个组合交换座位，共 90 局。每局在首次击倒时结束，否则在 7200 帧截断。1P 固定使用魔理沙，2P 固定使用灵梦。
每个种子分为 16 实例和 14 实例两批运行。

这里的 `community_combo` 和 `community_guard` 是[参考社区脚本实现的规则子集](community-ai.md)，不是完整神 AI。

## 结果

表内依次为**行策略的胜局数 / 负局数 / 超时局数**。每格六局；本次没有同时击倒。

| 行策略 / 列策略 | rush | zoning | counter | community_combo | community_guard |
| --- | --- | --- | --- | --- | --- |
| rush | 3 / 3 / 0 | 6 / 0 / 0 | 3 / 3 / 0 | 3 / 3 / 0 | 0 / 6 / 0 |
| zoning | 0 / 6 / 0 | 3 / 3 / 0 | 0 / 0 / 6 | 0 / 3 / 3 | 0 / 1 / 5 |
| counter | 3 / 3 / 0 | 0 / 0 / 6 | 3 / 3 / 0 | 3 / 3 / 0 | 2 / 2 / 2 |
| community_combo | 3 / 3 / 0 | 3 / 0 / 3 | 3 / 3 / 0 | 3 / 3 / 0 | 3 / 3 / 0 |
| community_guard | 6 / 0 / 0 | 1 / 0 / 5 | 2 / 2 / 2 | 3 / 3 / 0 | 3 / 3 / 0 |

74 局分出胜负，16 局超时。所有计划区组均完成，没有错误或缺失结果。记录中丢帧为零，对象观测没有溢出。
同一游戏种子下，所有对局的初始状态哈希一致。
15 个自我对战区组的两局在结束帧、胜负、奖励、初末诊断和规则计数上逐项一致，证明本次并行运行没有造成这些确定性策略的跨实例记忆混用。
这不等于验证了所有可能输入下的确定性。

新策略的记录包含 492 次 236B 指令序列启动、1768 帧普通攻击连段输入、80 帧空中接前 B 输入，以及 16286 帧站防输入。
这些计数证明规则与输入分支被执行，不等于每次输入都成功出招或命中。

`community_guard` 在这三个种子、两个座位组合下对 `rush` 六局全胜。它对 `counter` 是两胜两负两超时，对 `zoning` 仍有五局超时。
因此可以用它丰富固定对手集合，不能声称它全面强于已有策略。
只有三个独立区组；即使假定种子独立抽样，六局全胜对应的 95% Hoeffding 胜率区间仍为 \([0.2159,1]\)。本次固定种子不提供真实对局分布的抽样保证。
