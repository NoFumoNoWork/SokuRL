# 基于状态决策树的对战基线

这些策略不需要训练。每个模拟帧读取当前状态，依次判断条件，输出方向和按键。规则位于 `src/soku_rl/baselines.py`，配置集中在 `config/baselines.yaml`，使用 Hydra 加载和覆盖。

## 策略

| 配置名 | 行为 | 用途 |
| --- | --- | --- |
| `rush` | 接近对手，距离足够近时按 A，追赶空中的对手 | 近身压制基线 |
| `zoning` | 保持配置指定的距离，轮流使用 B、C，受挤压时后退或跳出角落 | 远程控距基线 |
| `counter` | 看见近距离普通打击动作时防守，看见远程攻击动作时接近，进入攻击距离后出招 | 观察后反击基线 |
| `idle` | 不输入任何按键 | 检查有效攻击的静止对照，不作为有对抗能力的策略 |

三个对战策略共享两项规则：灵力低时减少攻击并拉开距离；附近有敌方攻击对象时尝试跳跃和使用 D 回避。优先级由源码中的判断顺序确定。每个动作附有触发规则名称，对局报告会统计规则使用次数。

攻击按键按配置的帧间隔发送单帧脉冲，其余帧释放攻击键。方向输入可以连续保持。策略不使用符卡、特殊技能指令、连招搜索或预知未来状态。

## 输入与边界

`TreePolicy.act(Observation)` 返回 `Decision`。观测包含当前帧号、自身和对手的位置、生命值、灵力比例、动作编号、是否在空中、命中停顿，以及敌方攻击对象的位置和速度。策略不依赖 Windows、Wine 或共享内存，可以在 Linux 原生 Python 中调用。

对局运行程序负责把桥接状态转换为观测，再把策略输出送回游戏。双方分别得到以自己为主体的观测；前进和后退通过双方横坐标计算。

敌方对象必须处于活动状态且带有攻击框，才会进入回避判断。判断只按当前速度预测一段时间内的最近距离，忽略加速度、完整攻击框形状、消失时机和特殊弹幕规则，因此不能保证回避成功。近身防守依据固定版本 SokuLib 中的普通打击动作编号区间，不判断某一帧是否真正可以造成伤害。

距离、场地边界、灵力阈值和攻击间隔是人工选择的参数，尚未证明适合所有角色和场景。默认对局使用启动配置中的角色与场景。程序遇到对象观测超过共享内存容量时会报错，不能把缺失对象的回合计为有效结果。

## 运行循环对战

先在项目虚拟环境安装依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[rl]"
.\.venv\Scripts\python.exe tools/baseline_tournament.py
```

已配置 Wine 的环境使用相同的 Windows Python 运行程序，例如在服务器工作目录执行：

```bash
setup/run-python.sh tools/baseline_tournament.py
```

默认配置包含四种策略。每个种子运行全部十二种不同策略的有序配对，共三个种子、三十六个单回合。每种对战组合会交换策略所在的玩家位置。每个回合从新游戏进程开始，到任一方生命值归零，或达到 7,200 帧为止；后者记为 `timeout`，不能算作胜利。它不是游戏默认多回合赛制的一整场比赛。

可通过 Hydra 修改配置，例如：

```bash
setup/run-python.sh tools/baseline_tournament.py 'profiles=[rush,zoning,counter]' max_frames=7200
```

报告保存在 `logs/validation/baseline-tournament.json`。它记录每次配对的种子、角色、最终血量、最低血量、胜负或超时、模拟帧数、规则使用次数和丢帧计数；同时记录包含策略计算的采样速度、策略计算耗时和启动耗时。

样本量不足以证明策略强弱。先用它们检查环境是否能形成有效对抗，再作为 RL 策略的固定对手和回归评估对手。比较学习方法时需要固定角色、种子、回合时限和对手配置，并增加独立评估种子。
